# Search engine icons

These PNGs contain the official site favicon artwork, retrieved on 2026-11-08.
The largest available favicon frame was extracted without redrawing or recoloring.
Each PNG is 32 × 32 pixels with an RGBA transparency channel.

| Local asset | Official source |
| --- | --- |
| `bing.png` | https://www.bing.com/favicon.ico |
| `google.png` | https://www.gstatic.com/images/branding/searchlogo/ico/favicon.ico |
| `bilibili.png` | https://www.bilibili.com/favicon.ico |
| `douyin.png` | https://www.douyin.com/favicon.ico |

The Douyin favicon URL redirects to its official static asset CDN:
https://lf1-cdn-tos.bytegoofy.com/goofy/ies/douyin_web/public/favicon.ico

The Google static asset response is a PNG despite the `.ico` filename.
The other sources contain one 32 × 32 icon frame.
